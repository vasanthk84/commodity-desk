# Commodity Desk UI concepts

These screenshots are visual prototypes for review. All prices, OI figures, dates and report values shown in the images are illustrative.

- **Concept A — Research overview:** compact instrument selector, EIA report, price and OI charts, and a trade review panel on one screen.
- **Concept B — Market workspace:** a table-led watchlist, option OI analysis and EIA context alongside a simple review checklist.

Concept A was selected and implemented with live Kite and EIA data. The app shows an unavailable state when a source cannot provide data; it never uses the illustrative numbers from the screenshots.
