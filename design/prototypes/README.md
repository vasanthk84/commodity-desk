# Commodity Desk UI concepts

These screenshots are visual prototypes for review. They are not implemented in the app. All prices, OI figures, dates and report values shown are illustrative.

- **Concept A — Research overview:** compact instrument selector, EIA report, price and OI charts, and a trade review panel on one screen.
- **Concept B — Market workspace:** a table-led watchlist, option OI analysis and EIA context alongside a simple review checklist.

The live app remains on its earlier UI until a concept and any desired adjustments are selected.
